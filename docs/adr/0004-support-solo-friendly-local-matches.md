# Support Solo-Friendly Local Matches With Bot-Filled Player Slots

Chicken Olympics should support local matches with up to four player slots, and unused slots may be filled by bot chickens so one human can play a competitive solo local match. This keeps the core mode as a shared local competition with claims, scores, and a winner, instead of introducing a separate practice mode or high-score-only single-player mode.

Bot chickens are deliberately human-ish rather than optimal: they should make solo matches feel lively and winnable while still participating as normal player slots. This means the setup flow, match runtime, scoring, and presentation should treat human-controlled chickens and bot chickens as participants in the same local match rather than separate game modes.

Up to four player slots is not a promise that four humans can comfortably share one keyboard. The keyboard-friendly human count remains two for now; additional player slots should be bot-filled unless a later input approach, such as gamepads or multi-device controls, makes more human-controlled slots practical.

# Add Playtest Tuning Menu for Match Feel

We will add a hidden backtick-triggered Playtest Tuning Menu in `MatchScene` for tuning match feel, not a player-facing settings or difficulty menu. The first version will use freeform typed fields with unit hints, explicit Apply and Restart Match actions, validation that blocks applying invalid values, and `localStorage` persistence for applied tuning; Defaults will stage production defaults in the draft and clear saved tuning only when committed by Apply or Restart. Runtime-safe values such as Chicken Cursor Responsiveness, Bot Chicken Indecision, and claim feedback can apply live, while match construction values such as match length, Peek Pressure, Green Chick schedule/value, and peek slot count apply on restart; hiding spot layout editing is out of scope for v1.

# Runtime Asset Provenance Manifest

Committed runtime art and audio assets for Chicken Olympics belong in this
manifest when they are added to `public/assets/`.

## Required Fields

Each committed runtime asset entry must document:

- **Asset path**: Repo-relative path to the exported runtime asset.
- **Creator**: Person, team, tool, or vendor that created the asset.
- **Source**: Original source file, source URL, commission, or repo-owned note.
- **License**: License name and any required attribution text.
- **Usage**: Where the asset is used in the local match presentation.

## Entries

No committed runtime art or audio assets are registered yet. The current match
slice still uses procedural Phaser textures and generated WebAudio fallback
sounds until the first authored slice assets are added.
